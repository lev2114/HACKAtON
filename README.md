# Шаролёт

Браузерная 3D-мультиплеерная игра (three.js) про космическую станцию с
5 отсеками. В каждом отсеке — NPC (персонаж "Смешариков"), который
рассказывает научные факты о космосе и запоминает, что уже рассказал
конкретному игроку. ИИ-диалоги считаются полностью локально (гибрид:
конечный автомат + опционально локальная LLM через Ollama), игра работает
без интернета.

Хакатон-проект, делается за 2 дня. Подробная архитектура, протокол и
текущий статус — в [`CONTEXT.md`](./CONTEXT.md).

## Быстрый старт

```bash
# сервер (терминал 1)
cd server
go run ./cmd/server

# клиент (терминал 2)
cd client
npm install
npm run dev
```

Открыть адрес, который выведет Vite (обычно `http://localhost:5173`).

## Структура

- `world-data/` — данные станции (комнаты, NPC, факты).
- `server/` — Go-бэкенд (WebSocket, SQLite, ИИ-ответы NPC).
- `client/` — three.js-клиент.

Детали — в `CONTEXT.md`, `PROTOCOL.md`, `TASKS.md`.
