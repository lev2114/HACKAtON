# UPDATES.md — лог для синхронизации между людьми и ИИ-агентами

Новые записи добавляются **в начало** (сразу под этим описанием), не в
конец — так любой агент, читая только верхние 1-15 записей, видит самое
актуальное без скролла через всю историю хакатона.

Формат одной записи:

```
## YYYY-MM-DD HH:MM — Автор (агент) — короткий заголовок
- Что сделано / что изменилось.
- Что теперь работает, что сломано/не готово.
- [BREAKING] если менялся протокол/контракт — обязательно явно.
Следующий шаг: что логично делать дальше.
```

Пиши коротко (3-6 строк), это лог для быстрой ориентации, не отчёт.

## 2026-10-31 15:20 — Waypo1nt1 (Claude Code) — подключена 3D-модель стыковочного узла

- Тиммейт добавил сгенерированную сцену `starling-room.glb` (29 МБ, 988
  мешей) — перенёс её из `/assets` в `client/public/models/`, чтобы Vite
  отдавал её статикой (и чтобы она попадала в `client/dist` при
  офлайн-сборке).
- `world-data/rooms.json`: у `hub` новое поле `model` — URL модели.
  `server/internal/world/world.go`: добавлено поле `Room.Model`
  (`json:"model,omitempty"`), иначе сервер срезал бы его при отдаче чанка.
  **[BREAKING-ish]**: формат `Room` в `PROTOCOL.md` расширен необязательным
  полем `model` — обратной совместимости не ломает (старые комнаты без
  поля работают как раньше), но если делаешь свой парсинг `chunk.room` —
  учти.
- `client/src/world.js`: если у комнаты есть `model` — грузится GLB через
  `GLTFLoader` (с кешем по URL, чтобы не перекачивать 29 МБ при каждом
  повторном входе), автомасштабируется и центрируется по bounding box
  под комнату; пока грузится — показывается временная коробка-заглушка.
  Остальные 4 комнаты без поля `model` рендерятся как раньше (процедурный
  короб).
- Важно для тех, кто трогает `destroyRoom`/клонирование моделей: geometry/
  material клонов — общие с закэшированным оригиналом
  (`userData.sharedModel = true`), `destroyRoom` их специально не
  `dispose()`-ит, чтобы не сломать повторный вход в комнату.

Следующий шаг: сам не проверял визуально (нет браузерных инструментов в
этой сессии) — проверьте масштаб/центровку модели в хабе руками, при
необходимости поправьте `TARGET_SPAN` в `client/src/world.js`.
