# UPDATES.md — лог для синхронизации между людьми и ИИ-агентами

Новые записи добавляются **в начало** (сразу под этим описанием), не в
конец — так любой агент, читая только верхние 1-15 записей, видит самое
актуальное без скролла через всю историю хакатона.

Формат одной записи:

```
## YYYY-MM-DD HH:MM — Автор (агент) — короткий заголовок
- Что сделано / что изменилось.
- Что теперь работает, что сломано/не готово.
- [BREAKING] если менялся протокол/контракт — обязательно явно.
Следующий шаг: что логично делать дальше.
```

Пиши коротко (3-6 строк), это лог для быстрой ориентации, не отчёт.

## 2026-10-31 16:35 — Waypo1nt1 (Claude Code) — реальные дверные проёмы + переход срабатывает сразу

По фидбеку "прохожу через маяк, ничего не происходит" — старая версия
триггерила переход только когда игрок доходил до центра соседней комнаты,

- **Переход срабатывает сразу на пересечении проёма**, не после ещё
  нескольких секунд ходьбы в пустоте (`maybeAutoEnterNeighbor` в
  `client/src/main.js`). При входе игрок появляется чуть внутри новой

- **Процедурные комнаты (всё, кроме хаба) теперь круглые с настоящей
  вырезанной аркой в стене** (`THREE.CylinderGeometry` с `thetaStart`/
  `thetaLength`), а не сплошной короб с невидимым "разрешением проходить
  сквозь". Дыра физически видна.
- Коллизия (`main.js`) соответственно тоже круглая для этих комнат
  (раньше была прямоугольная AABB везде).
- **Нашёл и исправил баг направления**: перепутал порядок аргументов
  `atan2` — `THREE.CylinderGeometry` кладёт вершины как
  `x = r·sin(θ), z = r·cos(θ)`, а не наоборот. Из-за этого проём сначала
  встал на 90° не в ту сторону. Проверил через чтение geometry.attributes
  буфера меша в Playwright (не на глаз, глазами не видел) — после фикса
  дыра точно совпадает с направлением на хаб.
- Хаб (на модели) коллизию не менял — остался прямоугольный бокс-коллайдер
  под её приближённые габариты, см. известное ограничение в `TASKS.md`.

Проверено Playwright: геометрическая интроспекция (дыра в правильном
направлении), функциональный тест "иду в другую сторону от прохода —
упираюсь в стену ровно на границе радиуса" (−26.4 при расчётных −26.4),

  закрытия клиентом.

  тестирование в `AGENTS.md`/переписку) — минимальный репро без единой
